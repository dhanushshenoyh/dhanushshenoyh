## Featured Proof-of-Work

### 1. [CheckDk](https://checkdk.app) — Predictive Container & Cluster Linting CLI
> **Stack:** `Python` • `TypeScript` • `Docker AST` • `FastAPI` • `AWS`  
> **Links:** [Website](https://checkdk.app) • [GitHub](https://github.com/radheshpai87/checkDK) • [PyPI](https://pypi.org/project/checkdk/) • [npm](https://www.npmjs.com/package/@checkdk/cli)
* **What it does:** CLI utility that analyzes container definitions and cluster configurations before deployment, predicting configuration failure points and suggesting automated diff fixes.
* **Traction:** Published on PyPI and npm with **1,150+ combined downloads**.
* **Recognition:** Finalist at the **AI for Bharat AWS Hackathon**.

### 2. [Oppy](https://oppy.dshenoyh.in) — Terminal-Based Developer Opportunity Aggregator
> **Stack:** `JavaScript` • `Node.js` • `CLI Tooling` • `Web Scraping`  
> **Links:** [Website](https://oppy.dshenoyh.in) • [GitHub](https://github.com/abbysallord/oppy) • [npm package](https://www.npmjs.com/package/@dshenoyh/oppy-cli)
* **What it does:** Fast terminal interface that indexes and aggregates live developer opportunities (hackathons, remote internships, developer grants) from Unstop, Devpost, and We Work Remotely.
* **Features:** Intelligent skill-based matching to surface high-relevance listings directly in the developer's shell.
* **Traction:** **980+ downloads** on npm (`@dshenoyh/oppy-cli`).

### 3. [Kestrel](https://kestrel-assistant.streamlit.app) — Multi-Agent Hallucination Elimination Engine
> **Stack:** `Python` • `LangGraph` • `LangSmith` • `ChromaDB` • `Streamlit`  
> **Links:** [Live Demo](https://kestrel-assistant.streamlit.app) • [GitHub](https://github.com/abbysallord/kestrel-assistant)
* **What it does:** Orchestrates a 4-agent cyclical LangGraph workflow (**Planner → Retriever → Verifier → Synthesizer**) designed to systematically audit and eliminate factual hallucination in LLM outputs.
* **Engineering:** Instrumented with LangSmith for distributed run tracing, automated truth evaluation passes, and sub-150ms verification benchmarks.
